# Support

Use Discussions or a focused Issue for questions about using this hub. Before
opening a request, search existing Issues and verify that submodules are
initialized with:

```bash
git submodule update --init --recursive
./scripts/bootstrap.sh --check
```

Support requests must include the command, operating system, affected path, and
the exact error. Questions that are not reproducible may be closed or redirected
to the relevant submodule.
