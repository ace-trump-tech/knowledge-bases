## Review boundaries

- The hub owns navigation, metadata, submodule pins, CI, and governance files.
- Each linked repository owns its own source content, license, and release cycle.
- A submodule update must identify the upstream commit and summarize the change.

Maintainer changes are reviewed through pull requests whenever repository
settings permit. Emergency fixes are documented in the next release note.
